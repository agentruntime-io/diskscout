Category definitions

  
A category says how risky a duplicate is to remove. Each file is put in the first category (top to bottom) that has a matching rule; a category with no rules matches everything, so keep one last as the catch-all. Edit, then Save: the groups are re-sorted at once.

  
How to write rules
    
One rule per line, matched against the full path (case does not matter, / and \ are the same).

    
\downloads\ the path contains this   node_modules*\.bin * matches anything   ^c:\temp\ starts with   .vhdx$ ends with

    {home}\documents\ your profile folder   {otherusers} any other account's profile

    re:^[a-z]:\\te?mp\\ a regular expression

Preferred folders

  
When copies are identical, the one under these folders is suggested as KEEP (then the oldest, then the shortest path). One folder per line. This is only a suggestion; nothing is deleted without your say.

  
  




  
Folders and files that could not be read

  
Usually permission problems (system folders) or files that disappeared during the scan. They are left out of the totals, so they show up as "unaccounted" on a drive.
